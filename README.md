# ScrollPulse 🫧
[License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)

Scroll less. Live more.

ScrollPulse counts every scroll you make, with a live floating bubble, and tracks your Daily / Weekly / Monthly / Yearly totals.

### Features
- 🔢 Live scroll counter
- 🫧 Floating bubble you can drag anywhere
- 📊 Daily / Weekly / Monthly / Yearly stats
- 📈 7-day chart
- 🎯 Set your own daily goal
- 🏅 Badges for scrolling LESS: Chill Day, Focus Master, Scroll Ninja
- 🔊 Sound + vibration every 100 scrolls
- 🌑 Dark + Neon design
- 💾 All data saved on your device, nothing uploaded

### How to use
1. Open the live site
2. Scroll the test feed to try it
3. Tap the bubble to open the dashboard
4. Go to Settings to set your goal and permissions

### Permissions
- Display Over Other Apps - for the floating bubble on top of Instagram / TikTok / YouTube
- Accessibility Service - to count scrolls in other apps even when closed
- Notifications - for goal alerts

Built with HTML, CSS & JS in one file.
